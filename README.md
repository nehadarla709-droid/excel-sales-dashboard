## Bike Buyers Analysis – Excel Project

## Project Overview

This project is an end-to-end data analysis project created using Microsoft Excel. 
The project analyzes customer and bike purchasing data to identify patterns, trends, 
and insights that can support business decision-making.

## Project Structure

The Excel workbook contains the following worksheets:

- **Bike Buyers** – Raw/source dataset
- **Working Sheet** – Data preparation and analysis
- **Pivot Table** – Data summarization using Pivot Tables
- **Dashboard** – Interactive visualization of key insights

## Data Analysis Process

1. Imported and reviewed the raw dataset.
2. Cleaned and prepared the data for analysis.
3. Organized and analyzed the data using Excel.
4. Created Pivot Tables to summarize important information.
5. Created charts and visualizations.
6. Developed an interactive dashboard to present the findings.
